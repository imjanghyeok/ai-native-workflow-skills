# 필요한 범위만 탐색하고 전처리 근거 남기기

K-Dense-AI/scientific-agent-skills의 exploratory-data-analysis에서 필요한 분석 절차를 제한적으로 재구성했다. 고정 출처/허가 고지는 [THIRD_PARTY_NOTICES](../../../../THIRD_PARTY_NOTICES.md)에 있다. 원문의 Python 도구·라이브러리·보고서 강제 형식을 가져오지 않으며 JS/TS/기존 환경에서 적용한다.

- 분석 질문과 관측 단위(개체/사건/기간), 컬럼 의미·단위·범위·출처를 먼저 확인한다. 행 수를 서로 다른 개체 수로 오해하지 않는다.
- 실제 읽은 파일/범위·표본/전체·잘린 부분을 기록한다. 표본의 분포나 결측률을 전체 값이라고 쓰지 않는다.
- 결측·관측 실패·구조적 부재·진짜0을 구분한다. 자동0채움/보간/이상치 제거를 정책으로 만들지 않는다.
- 평균만 보지 말고 중앙값/분위수와 극단값 포함/제외 시 지표 변화를 필요한 범위에서 대조한다. 이상치 표시는 삭제 근거가 아니다.
- 시간/그룹별 반복 관측과 서로 다른 독립 개체를 구분한다. 예측/학습이 실제 요구라면 시간/개체 분할 뒤 학습구간에서만 결측 대체·스케일 등을 맞춰 누수를 막는다.
- 변환식·제외 이유·원본 스케일·재실행 설정/버전·출처를 남긴다. 탐색에서 찾은 상관을 원인으로 확정하지 않는다.

CSV/JSON/로그를 연결할 때 키/기간/단위를 정규화하기 전에 원문을 보존하고, 결합의1:1/1:N/N:M과 미매칭/행증식을 확인한다. 잘못된 행을 제외했을 때 어느 집단의 수요·비용이 빠지는지도 확인한다. 실제 검증과 독립 기대값은 [대조 규약](reconciliation.md)을 적용한다. 이 문서를 읽었다는 이유로 전처리 완료나 전체 데이터 검증을 선언하지 않는다.
