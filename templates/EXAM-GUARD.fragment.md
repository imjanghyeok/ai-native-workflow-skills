# 시험 작업 경계 · 필요한 내용만 기존 지침에 병합

이 파일은 자동 적용되지 않는다. 실제 과제 지침·최신 운영 메일을 먼저 확인하고, 기존 AGENTS.md를 통째로 덮어쓰지 말고 해당 내용을 병합하거나 Codex에 직접 읽힌다.

- 허용된 공개 준비물만 제공 환경에서 clone/다운로드한다. 저장소 URL·커밋·경로·적용/변경 범위를 과제 내부 문서에 기록한다.
- **git push, PR/이슈/Gist 작성, 업로드·외부 전송을 하지 않는다.** 시험 문제·파일·결과·작업 로그는 시험 공간 밖으로 공유하지 않는다. 다른 원격·도구로 우회하지 않는다.
- 외부 자료는 실제 과제를 이해하고 필요한 부분에 적용한다. 외부 완성 결과로 제출물 전체를 대체하지 않는다.
- 제공 Codex와 실제 허용 모델만 사용한다. Codex 업데이트·버전 교체·개인 AI 계정/API 연결·별도 모델·Computer Use를 사용하지 않는다.
- 새 MCP나 전역 도구 설치를 기본 전제로 삼지 않는다. 감독/플랫폼 연결과 제한 설정을 변경·종료하지 않는다.
- 원본 데이터·사용자 변경·기존 계약을 보존하고 삭제 후 재생성보다 작은 수정을 우선한다.
- 다중 Codex 허용을 확인하기 전에는 동시 세션을 생성하지 않는다. 여러 터미널을 열 수 있다는 사실과 별도로 확인한다.
- 실제 검증과 미확인을 구분한다. 제출 확정은 실제 응시 절차에 따르며, 후속 서술형에서는 AI와 복사·붙여넣기를 사용하지 않는다.
