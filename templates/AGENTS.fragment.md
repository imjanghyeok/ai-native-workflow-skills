# 코드 작성 가이드 조각

이 파일은 기존 AGENTS.md에 필요한 항목만 병합하거나 Codex에 직접 읽히기 위한 예시다. 기존 AGENTS.md 전체를 대체하는 파일이 아니다.

## 코드를 수정할 때

- 먼저 수정 범위에 적용되는 프로젝트 지침·README·포맷터·린터·타입·테스트 설정과 주변 구현을 확인한다.
- 첫 변경 전에 적용할 명명·파일 배치·입출력·오류 처리·검증 규칙과 출처를 짧게 정리한다. 명시된 규칙과 추정한 관례를 구분한다.
- 기존 실행 방식·패키지 관리자·인터페이스·모듈 책임에 맞춰 구현한다. 요구와 관계없는 리팩터링·전체 포맷·의존성 교체를 섞지 않는다.
- 규칙이 없으면 선택한 언어에 맞는 단순한 기본값을 일관되게 적용한다. 과제와 맞지 않는 특정 스택·스타일을 강제하지 않는다.
- 실제 존재하는 프로젝트 명령으로 필요한 검사를 수행한다. 확인하지 않은 검사를 통과했다고 쓰지 않는다.
- 시험 작업이면 git push·PR/업로드·작업 자료 외부 전송과 Codex 업데이트를 하지 않는다. 최신 운영 안내를 확인하고 EXAM-GUARD.fragment.md의 해당 경계를 필요한 만큼 함께 적용한다.
- 상세 절차가 필요하면 설치된 implement-and-verify 스킬의 references/conventions.md를 읽는다. 해당 파일이 없으면 위 규칙과 실제 프로젝트 지침으로 진행한다.
