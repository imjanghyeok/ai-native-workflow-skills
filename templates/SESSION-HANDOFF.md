# 작업 단위 인계 양식

작은 과제는 기존 문서 안의 표로 충분하다. 이 파일 전체를 매번 생성할 필요는 없다. 기록은 실제 시험 작업 공간 안에만 보관한다.

| 항목 | 실제 작업 기준으로 작성 |
| --- | --- |
| 역할/작업 단위 | 구현/자료 분석/리뷰 등; 실제 독립 세션인지 같은 세션의 역할 전환인지 |
| 목표·R-ID | 원문에서 충족할 조건 |
| 읽기/쓰기 범위 | 소유 파일·공통 계약·수정하지 않을 파일 |
| 입력·응답·오류 계약 | 합의한 형식과 동률·미매칭 등 업무 규칙 |
| 완료 기준 | 관찰 가능한 기대 결과 |
| 변경 파일·적용 자료 | 실제 파일과 사용한 공개 자료 URL/커밋/경로/사용 범위 |
| 검증 근거 | 실제 명령·입력·기대/관찰값·종료 상태 |
| 미완료·가정·한계 | 확인된 사실과 분리 |
| 리뷰 발견 | 심각도·파일 위치·근거·재현 방법·영향; 코드 수정은 담당자에게 인계 |
| 다음 행동 | 필요한 최소 후속 작업과 담당 범위 |
