# 알고리즘 선택과 대안 비교

이 문서는 특정 산업의 답안이나 최적화 패키지를 제공하지 않는다. 실제 수요·결정변수·정책·규모가 확인된 뒤 필요한 방법만 고른다.

| 구조 | 먼저 검토할 후보 | 주의할 한계 |
| --- | --- | --- |
| 집계/점수순 후보 선택 | Map·정렬·명시적 규칙 | 점수순 선택만으로 전체 용량/상호 제약 충족을 보장하지 않음 |
| 아주 작은 조합 | 완전탐색/분기 한정 | 조합 증가·시간 제한; 작은 정답 검증용과 실제 규모를 구분 |
| 제한된 정수 용량/금액 | 동적 계획법 | 상태 범위/정밀도에 따른 시간·메모리, 제약 구조가 맞는지 |
| 독립 비용의1:1 또는 흐름 배정 | 매칭/최소비용흐름 | 다단 일정/복잡한 결합 제약을 자동 해결하지 않음 |
| 경로/연결/선행관계 | 최단경로/위상정렬 | 하나의 경로나 순서가 전체 배정·자원 충돌 해결은 아님 |
| 일정/배분의 결합 제약 | 제약계획/정수계획, 준비된 solver | 이산/연속·모델 선형성·지원 제약·설치/시간 예산·해 상태 확인 |
| 큰 조합·다목적 절충 | 탐욕+국소개선/휴리스틱, 필요시 다목적 탐색 | 근사·seed/반복·검증 필요, Pareto 후보집합은 전체 Pareto 최적성 증명이 아님 |

규칙이 바뀌면 가정/모델 적합성도 바뀐다. 최단경로·군집·예측 하나를 전체 운영 최적화로 부르지 않는다. 공개 도구의 예제를 실제 계약 대신 쓰지 않는다. 필요한 새 패키지는 라이선스/버전/기존 환경/허용 범위를 확인한 뒤 도입한다.

## 비교 표에 담을 최소 근거

- 입력·설정·기간·자원·비용 산식 버전과 후보 식별자.
- 필수 제약 검사와 위반 항목/크기, 처리/미처리/중복·손실 및 보존 합계.
- 동일 정의로 계산한 목적값·품질/서비스·자원/비용·관련 집단 영향.
- 기준안 대비 차이와 방향. 절감률은 기준값이0이면 계산 불가로 표시하고 절대 차이를 제공한다.
- 후보가 더 나은 조건/나빠지는 조건, 가정 변화의 민감도, 채택/거절 주체/이유와 미검증.

같은 후보 데이터에서 최적화 내부 계산과 별개로 제약을 재검사한다. 정책·평가기 정의는 공유 계약으로 유지하되 후보 생성의 오류를 그대로 복제한 계산만으로 정확성을 주장하지 않는다. 생성된 CSV/JSON/배정표를 실제로 재읽고 누락·ID·타입·단위와 목적/제약을 대조한다. 일부 입력 누락이나 실패를 제외한 뒤 분모를 줄여 성과가 개선된 것처럼 보이지 않게 한다.

시간 초과 시 유효한 현재 후보가 있으면 그 상태와 미증명 최적성을 보고한다. 유효 후보가 없으면 `해를 찾지 못함`과 위반/오류를 보고한다. 엄밀한 불가능 판정이 확인된 경우만 `실행 불가능 증명`이라고 쓴다. 요구가 전체 처리를 필수로 정했다면 일부 누락에 페널티를 붙였다는 이유로 실행 가능하다고 바꾸지 않는다.
