# 공개 준비물과 시험 작업의 경계

사용자가 전달한 운영 메일과 가이드를 바탕으로 정리한 준비용 지침이다. 공식 안내를 대체하지 않으며, 서로 다르면 **최신 운영 메일의 명시 사항을 우선**하고 별도 안내가 없는 부분은 가이드를 따른다. 개인 접속 링크·원문 시험 자료는 이 저장소에 포함하지 않는다.

## 가져오기와 사용

- 공개 저장소의 지침·Skill·하네스·템플릿·코드는 실제 가이드의 허용 범위에서 가져와 사용할 수 있다. 사용하는 저장소는 2차 예선 결과 통지 전까지 공개 상태로 유지한다. 비공개 저장소나 개인 PC 파일 업로드 경로는 사용하지 않는다.
- 허용된 clone/다운로드와 작업 자료의 외부 전송을 구분한다. 자료 접근은 실제 플랫폼 안내에 따라 제공 환경의 AI·터미널 안에서 진행한다.
- 기존 프로젝트와 실제 요구사항을 먼저 읽고 필요한 부분만 활용한다. 외부 완성 결과로 전체 제출물을 대체하지 않는다. 범용 시작본이 실행되는 것만으로 실제 과제 완료가 되지 않는다.
- 사용한 저장소 URL·커밋·참고 경로·복사/수정한 범위·선택 이유를 기존 설계/검증 문서에 짧게 남긴다. 실제로 읽거나 사용한 범위만 기록한다. 공개 저장소에 이 사용 기록이나 시험 자료를 다시 올리지 않는다.

## 시험 작업에서 금지할 외부 쓰기

**git push를 실행하지 않는다.** PR·이슈·Gist·릴리스·파일 업로드·외부 전송 API·메신저 등으로 문제·코드·데이터·결과·작업 기록을 전송/공유하지 않는다. 외부 저장소로 제출하는 일반 개발 습관을 이 시험에 적용하지 않는다. 새 원격을 추가하거나 다른 전송 경로로 제한을 우회하지 않는다. 제출은 시험 플랫폼의 지정 절차로 한다.

이 지침은 시험 과제 작업의 경계다. 시험과 무관한 범용 준비 묶음을 사용자가 별도로 공개·관리하는 작업과 혼동하지 않는다. 하네스의 이벤트·실행 로그도 시험 공간 안에만 남긴다.

## 제공 AI와 환경

- 과제 AI는 제공된 Codex를 사용한다. 운영 메일의 권장 표기는 **6.1 Sol, 5.6 Terra, 6.0 Luna**다. 실제 제공된 선택지를 확인하며 임의의 모델 ID나 개인 계정/API 연결을 설정하지 않는다. 가이드의 Astra 제한도 실제 최신 안내에 따라 지킨다.
- **Codex 업데이트 금지.** 업데이트 권유를 수락하거나 설치·전역 업데이트·버전 교체 명령을 실행하지 않는다.
- 별도 AI 모델 연결·제한 우회·Computer Use를 사용하지 않는다. 새 하네스나 스킬을 읽는다고 이 기능을 사용할 권한이 생기지 않는다.
- 감독/플랫폼 설정·연결 프로세스를 변경/종료하지 않는다. 오류는 발생 시각·증상·단계를 시험 내 문제 신고로 알린다. 토큰·키·개인 링크를 로그에 쓰지 않는다.
- 후속 서술형에서는 AI·복사·붙여넣기를 사용하지 않고 본인이 직접 답한다.

## 여러 제공 세션

가이드의 터미널 탭/분할 기능만으로 다중 Codex 허용을 추정하지 않는다. 다만 사용자가 실제 같은 제공 환경의 동시 사용 허용을 확인해 전달했다면 그 확인을 사용하고 같은 질문을 반복하지 않는다. 지원 세션 수·제공 모델·자원 한도 내에서 일감을 분리하며, 다른 계정·외부 모델·새 접속 경로를 만들지 않는다.

## 범용 준비물과 실제 과제 자료

[문제 중립성 기준](problem-neutrality.md)에 따라 공개 묶음에는 일반 절차·빈 양식·최소 문법 참고만 둔다. 실제/재구성 과제, 고유한 데이터·정책·주제·완성 설계/답안·개인 판단/로그는 공개하지 않는다. 실제 내용을 채운 코드맵·의사결정·일감 보드는 시험 환경 내부 자료다. 규정에 따른 준비 범위 판단이며 운영팀의 개별 사전 승인을 보장하지 않는다.

## 클라우드 준비와 전송

클라우드에 맞춘 설정/문서·실행 구조 준비와 실제 코드 업로드/배포는 구분한다. 과제에서 명시적으로 제공한 내부 배포 절차는 해당 안내를 따르되, 외부 전송 금지에 반하는 개인 호스팅·Git push·외부 문서/다이어그램 서비스 전송은 하지 않는다. 이번 준비 묶음은 MCP를 사용하지 않는 경로를 택한다. 가이드상 MCP 자체가 일괄 금지되거나 항상 외부 AI 에이전트라는 뜻은 아니다.
