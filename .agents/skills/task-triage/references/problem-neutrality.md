# 문제를 담지 않는 공개 준비물

공개 저장소는 재사용 가능한 작업 방법이다. 이미 본 문제를 재구성해 넣거나 재응시 답안을 밖에서 만들어 가져오는 경로로 사용하지 않는다.

## 공개해 둘 것과 내부에 남길 것

| 공개 준비물 | 실제 시험 공간 내부에서만 작성 |
| --- | --- |
| 원문 분석·가공·설계·구현·검증 절차 | 실제 원문 요구·데이터·정책·질문/답변 |
| 빈 일감/결정/코드맵 양식 | 내용을 채운 일감·판단·코드맵·실행 기록 |
| 언어/프로젝트에 따라 고르는 컨벤션 | 실제 프로젝트 코드·설정·제출물 |
| 최소 다이어그램 문법 참고 | 실제 과제 아키텍처·API·의존성 그림 |
| 라이선스/출처가 명확한 범용 일부 참고 | 고유한 문제 조합·수치·풀이·완성 답안 |

실제 과제의 주제·이름을 지우는 것만으로 익명화가 끝나지 않는다. 특징적인 데이터 구조·정책·역할 조합·알고리즘/설계·숫자·예외가 함께 남아 문제를 복원할 수 있으면 제외한다. 스킬이 임의의 주제·프레임워크·인증/역할·최적화·배포를 모든 과제에 강제하지 않게 한다.

새 과제에서는 원문을 읽어 경로를 고르고 필요한 준비물만 적용한다. 실제 답안·완성 구조를 미리 고정하지 않는다. 라이선스가 허용해도 외부 완성물을 제출물 전체로 대체해도 된다는 뜻은 아니다.

## 안내와 대조한 범위

2026-11-04에 사용자가 제공한 브리프의 제한/공개 자료 항목과 상세 가이드의 도구·자료 허용/외부 전송 항목, 대화에 제공한 후속 운영 메일을 대조했다. 원문 PDF·메일·개인 링크는 이 저장소에 복사하지 않는다. 이 표는 준비용 해석이며 공식 승인서가 아니다.

| 확인한 안내 | 이 묶음에 적용한 경계 |
| --- | --- |
| 공개 Skill/저장소·일부 소스 활용, 결과물 통째 대체 제한 | 범용 자체 스킬 + 선별한 문법/검토 기준 + 출처/라이선스; 답안 없음 |
| 문제·파일·결과 외부 공유/전송 금지, Git Push 불가 | 실제 과제 코드·그림·자료·기록은 시험 공간 내부 유지 |
| 비허용 외부 도구로 답안 생성·반입 제한 | 과거 문제를 재구성한 답안·도메인 풀이를 공개 준비물에 넣지 않음 |
| 제공 AI·모델/버전·자동 조작/감독 제한 | 제공 Codex와 실제 허용 모델, 업데이트/외부 AI/Computer Use 없음 |
| 후속 서술형 AI/복사·붙여넣기 제한 | 이해 자료는 허용된 작업 단계/연습에 작성; 실제 후속 답변은 본인 작성 |
| 운영 메일의 공개 유지 조건 | 사용 저장소는 결과 통지 전까지 공개 유지; 새 안내가 있으면 우선 |

다중 제공 세션 허용은 이번 사용자가 확인해 전달한 조건이다. 원래 가이드의 탭 기능만으로 추론한 사실이 아니며 다른 환경의 허용으로 일반화하지 않는다. MCP는 안내상 일괄 금지라서가 아니라 이 준비 방식에서 의존성을 줄이기 위해 제외한다. 실제 클라우드 업로드도 별도 허용/지정 경로 없이 수행하지 않는다.

## 공개 변경 전 확인

준비물 변경 diff만 검토한다. 실제 과제 작업 디렉터리/로그를 통째 복사하지 않는다. 공개 allowlist에 맞는 파일인지, 도메인 사례/개인 링크/비밀값/채운 양식이 섞이지 않았는지, 외부 원문의 출처·고지·필요한 부분만 포함됐는지 확인한다. 키워드 검사만으로 비공개 정보 유무를 완전히 보장할 수 없으므로 내용도 검토한다.

사전 체험에서 본 질문의 원문·고유 내용·구현/답변도 공개 준비물로 복사하거나 재구성하지 않는다. 일반적인 기능/코드책임/실제 검증 근거 정리와 제공환경 사용 절차만 독립적인 작업 방법으로 작성한다. 실제 후속 문항의 답안을 만들거나 AI/자료 열람 금지 단계로 반입하는 사용법을 추가하지 않는다.
